Tab-by-tab recommendations, weighted by you.

Every card below is a concrete, code-anchored change to the Image, Video, or Layout tab (plus app-wide moves). Select the ones you want, set a weight from 1–10, and export — export as many differently-weighted bundles as you like; the aggregator at the bottom merges them into a single ranked backlog. Weight 10 = top choice.

01 /

How to use this page

1. Click cards to select them. Selections persist in your browser between visits. 2. Label the bundle and pick a weight in the bottom bar (10 = "this is my top choice", 1 = "nice to have"). 3. Export — Copy JSON, Download, or Copy MD. Repeat with different selections and weights as often as you like; the companion pages (Dzine-informed, RenderZero-informed) export the same option IDs, so their bundles merge here too.

When you're done, paste all exports into the aggregator below — it ranks options by best weight, then total weight, then how many exports include them. Save the JSON files somewhere like:

D:\Documents\Code\GitHub\ImageAI\Plans\issue-11-ux-proposals\exports\
These are proposals, not replicas. Per the investigation on issue #11, no third-party UI is copied here — competitor products were researched for features and transferable patterns only (see Sources). All mockups are original ImageAI designs in the existing Maestro theme. Dzine and RenderZero names/trademarks belong to their owners.

03 /

App-wide options

These cut across all tabs. They're where most of the "techy" feeling dies.

GLB-01

Simple / Advanced UI mode

A persisted ui_mode setting (View → Simple Mode). Simple hides the LLM provider/model row, the Templates/Layout/Batch Jobs tabs, and collapses all disclosure sections. Widgets are hidden, never deleted, so nothing breaks. Fresh installs default to Simple; existing installs stay Advanced.

effort Mimpact highmain_window.py:601-625 · core/config.py
GLB-02

First-run setup wizard

On startup with no API key configured: a 2-step dialog — pick a provider → paste key → test call → land on the Image tab in Simple mode. Reuses the key handling that already lives in Settings. Today the app drops straight into the full pro surface.

effort Mimpact highgui/__init__.py:85-86 · settings_widgets.py
GLB-03

Primary-action button style

One primary QSS class in gui/theme.py (cyan fill + glow), applied to exactly one button per surface: Generate, Render Video, Fill all regions. Every screen answers "what do I press?" at a glance.

effort Simpact hightheme.py · main_window.py:917
GLB-04

One "AI Tools ▾" menu

Generate Prompts, Ask About Files, Ask About Prompt, and Prompt Builder fold into a single menu button. Keyboard shortcuts stay via QShortcut; the hint strip updates. The ten-button row becomes four items.

effort Simpact highmain_window.py:894-946
GLB-05

8 tabs → 4 workspaces

Create · Video · Layout · Library (Templates + History + Batch Jobs), with Settings/Help behind a gear. The genuinely studio-like restructure — needs its own design cycle and a tab-index audit before code.

effort Limpact highmain_window.py:601-625
GLB-06

Friendly model names

Combos show display names ("Nano Banana Pro") with the raw ID in a tooltip, resolved through the model registry. Raw IDs like gemini-2.5-flash-image are the single widest jargon surface a newcomer sees.

effort Simpact medmain_window.py:793-826
GLB-07

Unify project & save semantics

Ctrl+S and the File menu act on video projects only, while Layout has its own New/Open/Save buttons — the same shortcut means different things per tab. Route File actions through the active workspace.

effort Mimpact medmain_window.py:683-711 · layout_tab.py:59-96
GLB-08

Empty-state guidance

Blank canvases become a short numbered "start here" (Image: 1. describe → 2. Generate. Video: 1. New project → 2. paste lyrics → 3. Generate Storyboard). No new windows — just purposeful empty states.

effort Simpact highmain_window.py:1428-1433 · wizard_widget.py:129
GLB-09

Key deep-links & honest billing notes

Settings and the first-run wizard link each provider straight to its key-creation page and its billing page, with a plain note about which models need paid billing. RenderZero validates the deep-link pattern — and its contradicted "free tier" marketing is the anti-pattern we avoid by being honest.

effort Simpact highpattern: RenderZeromain_window.py:1650 · settings_widgets.py
GLB-10

Non-blocking generation queue

A local queue with per-job progress so generating never blocks the UI — keep working while jobs render. Distinct from the cloud Batch Jobs tab (provider batch APIs); name them clearly apart. RenderZero's render queue proves the pattern in a desktop BYOK app.

effort Limpact medpattern: RenderZeroQThread worker · main_window.py:612-625

Video tab

The Video workspace is genuinely a pro tool — the fix isn't to dumb it down but to make its existing Workflow Guide the spine and stage the density. A newcomer should meet steps, not thirteen columns.

VID-01

Make the Workflow Guide the spine

The wizard pane already exists and is visible by default. Strengthen it: numbered steps double as navigation, the current step is highlighted, and its action button always mirrors the next move — including a real "start here" state when no project is loaded.

effort Simpact highworkspace_widget.py:423-452 · wizard_widget.py:129
VID-02

New-project quick start

One dialog wrapping the first three steps: name → paste lyrics/text (or Load File) → pick style + provider → project is created and storyboard generation starts. It wraps existing calls; no new pipeline.

effort Mimpact highvideo_project_tab.py:1614+ · workspace_widget.py:833-935
VID-03

Demote the LLM provider panel

The first thing the Video tab shows is a full-width LLM provider/model row. Move it into the Generation Settings disclosure next to the image provider — same controls, sane order.

effort Simpact medworkspace_widget.py:863 · :1105
VID-04

One primary render action

Apply the primary style to Render Video and give the disabled state a reason ("add scenes to render") instead of a silently greyed button.

effort Simpact medworkspace_widget.py:1660-1806
VID-05

Storyboard: progressive columns

Thirteen columns is the densest surface in the app. Simple mode shows a core set (#, Time, Source, Video Prompt, 🎬); a per-scene detail drawer carries start/end frames, refs, environment, and per-scene prompts. Full table stays in Advanced.

effort Limpact highworkspace_widget.py:1578
VID-06

Collapse secondary groups by default

Input Options, Generation Settings, and Music all start expanded — three open accordions before the storyboard. Start them collapsed (in Simple mode) and persist the state per project.
