A small field guide


    

  • Run discovery first. Its returned schema is the authority for the checkout you execute.
    • 

  • Copy an existing project for experiments. Use returned project paths and action IDs.
    • 

  • Imports use local media. Cards, plates, turnaround views, rendering, refinement and retouching call providers.
    • 

  • Process completed actions, then preview GIFs. Export refuses stale stabilization and incomplete profile output.
    • 

  • Both enabled profiles export by default. Choose HD, pixel, or both in the request.
    • 

  • CLI undo history persists between invocations and is separate from GUI history. Intervening project changes can invalidate it.
    • 

  • Structural CLI frame edits preserve order, count and accepted transparency through forced processing. Undo restores an emptied frame list.
    • 

  • Ambiguous generated sheets keep their saved image and accepted frames. Inspect the sheet, then recover with an explicit import-sheet grid.
    • 

  • Use key-preview for a quick chromakey MP4. Use ml-status before optional backend installation; ml-install starts as a dry run.
    • 

  • Inspect saved state after interruption before retrying a paid call.
    •
